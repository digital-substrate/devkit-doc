# Using your generated SDK

Kibo turns your DSM model into a typed package you work against every day — the
consumer surface that sits on top of the Viper runtime. The principle is shared
across languages (the {term}`Dual Reality`: typed classes over one runtime value,
produced by {doc}`kibo-template-viper <../kibo-template-viper/index>`), but the
surface is idiomatic to each. Pick your language:

```{toctree}
:maxdepth: 1

python
node
cpp
```
